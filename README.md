# Anki ImageSearchAddon

Validated to work on Windows in the following Anki versions:
- Anki 26.09.3 (Qt6.11.2, Python 3.13.15), released Sep. 23, 2026
- Anki 2.1.15 (Qt5.12.1, Python 3.6.7), released Aug. 28, 2019

### Run

| Mode | Command |
|------|---------|
| In Anki (copy files) | `.\copy-to-anki.bat` |
| In Anki (launch) | `.\run-anki.bat` |
